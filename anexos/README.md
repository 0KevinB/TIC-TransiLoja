# Anexos - TransiLoja

Este directorio contiene documentación, diagramas, esquemas de datos y resultados de pruebas del proyecto TransiLoja.

## 📋 Contenido

### 📊 Diagramas y Documentación

- **[Diagrama C4 de TransiLoja](./Diagrama-C4-TransiLoja.md)** - Diagrama de arquitectura C4 del sistema TransiLoja, mostrando los diferentes niveles de abstracción (Contexto, Contenedores, Componentes y Código).

### 🗄️ Esquemas de Datos

#### Visualizador Interactivo
- **[Esquemas de Datos (HTML)](https://0kevinb.github.io/TransiLoja/anexos/Esquemas-Datos.html)** 🌐 - Visualizador interactivo de los tres esquemas de datos principales del proyecto.

#### Archivos de Datos
- **[Esquema de Datos de TransiLoja (JSON)](./Esquema%20de%20datos%20de%20TransiLoja.json)** - Estructura de datos completa de Firebase utilizada en TransiLoja.
- **[Estructura de Datos Exportados OSM (GeoJSON)](./Estructura%20de%20datos%20exportados%20(OSM).geojson)** - Datos geográficos exportados desde OpenStreetMap.
- **[Esquema de Archivos GTFS](./Esquema%20de%20archivos%20GTFS/)** - Directorio con los archivos del esquema GTFS (General Transit Feed Specification).

### 🧪 Resultados de Pruebas

- **[Resultados de Pruebas - App Móvil](./App-Movil-Resultados/)** - Capturas de pantalla, videos y reportes de pruebas de la aplicación móvil.
- **[Resultados de Pruebas - Web](./Web-Resultados/)** - Capturas de pantalla, videos y reportes de pruebas del portal web.
